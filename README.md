# مدير الميزانية - Budget Manager 💰

تطبيق ويب متكامل وسهل الاستخدام لإدارة ميزانيتك الشخصية، تتبع نفقاتك، ومعرفة أين تذهب أموالك من خلال تقارير ورسوم بيانية تفاعلية.

## 🌟 الميزات الرئيسية

- **تتبع الدخل والمصروفات**: إضافة عمليات الدخل والمصروفات بسهولة وتصنيفها.
- **تحديد الميزانية الشهرية**: ضع ميزانية شهرية وتلقَّ تنبيهات عند اقتراب استهلاكها.
- **دعم عملات متعددة**: إمكانية تغيير العملة الافتراضية لمعظم العملات المتاحة حول العالم (تلقائياً العملة الأساسية هي الدولار USD).
- **التصنيفات**: تصنيف المصروفات لفهم عاداتك الشرائية (طعام، نقل، فواتير...).
- **رسوم بيانية تحليلية**: عرض البيانات على شكل رسوم بيانية تفاعلية باستخدام Chart.js.
- **تصدير واستيراد البيانات**: إمكانية الاحتفاظ بنسخة احتياطية من بياناتك بصيغة JSON واستعادتها.
- **الوضع الليلي (Dark Mode)**: تبديل سلس بين الوضعين النهاري والليلي لراحة العين.
- **حفظ محلي (Local Storage)**: جميع البيانات تُحفظ محلياً في متصفحك للحفاظ على خصوصيتك وسريتك.
- **تصميم متجاوب**: يتوافق مع جميع الشاشات والأجهزة المحمولة.

## 🚀 كيفية الاستخدام والتثبيت

لا يحتاج التطبيق إلى قاعدة بيانات أو خادم، فهو يعمل مباشرة من خلال المتصفح باستخدام `localStorage`!

1. قم باستنساخ المستودع (Clone) أو تحميل الملفات بصيغة ZIP.
2. افتح ملف `index.html` في أي متصفح ويب حديث.
3. ابدأ بإضافة دخلك عبر الأزرار، وتحديد ميزانيتك، ثم سجل المصاريف اليومية.

## 🛠️ التقنيات المستخدمة

- **HTML5**: هيكلة الصفحات.
- **CSS3**: التصميم التفاعلي، المتغيرات (Variables)، والوضع الليلي.
- **JavaScript (ES6+)**: كتابة منطق العمليات، إضافة التفاعلات للواجهة، وحفظ البيانات.
- **Chart.js**: لإنشاء الرسوم البيانية التفاعلية للإحصائيات.
- **FontAwesome**: للأيقونات التوضيحية.

## 💱 دعم العملات

استجابةً لتعدد الفئات المستخدمة للتطبيق، أضيفت ميزة تبديل العملات لتدعم المستخدمين دولياً، وبشكل افتراضي العملة الآن هي **الدولار الأمريكي (USD)** مع إمكانية التغيير عبر القائمة المنسدلة في الشريط العلوي لأي من العملات المدعومة وسيتم تحديث الواجهة فوراً!
